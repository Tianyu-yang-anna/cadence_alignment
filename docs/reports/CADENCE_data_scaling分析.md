## ★ 更正声明（撤回基于 val 的拐点结论）

**先前基于 val 曲线报告过"~100B 拐点 / 粗尺度在 204.8B 过拟合回升"——此结论
作废。** 在独立 test split（3000 窗）上:
- 总 loss **一路单调降到 204.8B**（3.554→3.434,无平台）;
- 粗尺度**也在降**（4.068→4.009,无回升,无过拟合）。

val 上看到的"粗尺度 4.567→4.631 回升 / 总 loss 平台"是 **val split 的假象**
（在线记录、样本少）。教训与本波反复吃到的一致:**以 test 为准,val 单点不可
信**（同 sel→test 倒挂）。下文全部以 test 为准。

## 三个定量结论（全部基于 test，8 点）

### 1. 总损失稳定幂律下降,到 16 epoch 仍未饱和
test seg-bits 八点幂律拟合 **loss ∝ tokens^(−0.060)**,2B→204.8B 从 4.465
一路降到 3.434,**跨 0.2→16 epoch 单调下降、无平台、无拐点**。含义:100M 模型
在 OWT2 上反复过 16 遍数据仍在受益,**data scaling 收益远未耗尽**。

### 2. ★分尺度斜率差 17×——CADENCE 特色 signature
把损失按尺度轴拆开,两条曲线斜率天差地别:
- **coarse（语义,q1-q32）:幂律指数 −0.009,近乎水平**（4.195→4.009,总降 4%）;
- **fine（词面,q128-q1024）:幂律指数 −0.161,陡降**（4.606→2.316,总降 50%）;
- **斜率比 ≈ 17×**,且 fine 在 2B 时**高于** coarse（词面最欠训）、在 ~6.4B
  处**穿过** coarse 之下,此后一路走低,到 204.8B 仍无收敛迹象。

**这是 next-scale prediction 独有、别人物理上画不出的 scaling 结论**:
data scaling 的收益 ~17:1 压倒性流向**细尺度词面渲染**,而**粗尺度语义规划在
2B 就基本学够、几乎不吃数据**。它把"loss 降了"升级成"降在结构的哪一层":
CADENCE 的层级里,语义计划早饱和,规模几乎全用来提升词面渲染。与自适应实验
（难度/信息集中在中细带）、以及段轴/2D 的机制结论完全自洽。

### 3. 生成质量弱正向,无稳健饱和拐点（交叉榜核对后收窄）
- **R1/R2**:四榜大体**弱正向到持平**,wiki R2 4.06→5.03 稳步升,R1 噪声中
  略升;到 204.8B 未见退化。
- **MAUVE**:**没有跨榜一致的拐点**。wiki MAUVE 在 51.2B 达峰 0.195 后回落
  （0.174→0.161）,但 **wikisource 反而一路升**（0.091→0.105→0.108）,
  tinystories/1bw 全程 <0.008 属地板噪声。因此"wiki MAUVE 51.2B 拐点"是
  **单榜现象,不构成稳健的预算饱和信号**——报告时不上升为结论。

**综合:到 204.8B（16 epoch）teacher-forced loss 与生成质量均未出现稳健饱和
拐点。** 唯一稳健的结构信号是分尺度剪刀差。

## 对 model scaling 的指示（data scaling 一阶结论）
1. **token 预算不应停在 12.8B（1 epoch）**:100M 在 204.8B 仍未饱和,固定预算
   若太小会饿死大模型。可取幂律仍陡的区间;考虑到 fine 斜率在 ~50B 后趋缓、
   而生成质量无稳健拐点,**50–100B（4–8 epoch）是收益/算力的合理折中**,
   model scaling 固定预算建议落在此区间。
2. **分尺度互补假设**:data scaling 的收益几乎全在 fine（词面）。若放大模型
   主要提升 coarse（语义容量),则 model scaling 与 data scaling 改善的是层级
   的不同层——**这是 model scaling 阶段值得专门用同一张分尺度图验证的假设**。
