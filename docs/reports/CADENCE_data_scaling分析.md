## ★ 更正声明（撤回基于 val 的拐点结论）

**先前基于 val 曲线报告过"~100B 拐点 / 粗尺度在 204.8B 过拟合回升"——此结论
作废。** 在独立 test split（3000 窗）上:
- 总 loss **一路单调降到 204.8B**（3.554→3.434,无平台）;
- 粗尺度**也在降**（4.068→4.009,无回升,无过拟合）。

val 上看到的"粗尺度 4.567→4.631 回升 / 总 loss 平台"是 **val split 的假象**
（在线记录、样本少）。教训与本波反复吃到的一致:**以 test 为准,val 单点不可
信**（同 sel→test 倒挂）。下文全部以 test 为准。

## 三个定量结论（全部基于 test，8 点）

### 1. 总损失稳定幂律下降,到 16 epoch 仍未饱和
test seg-bits 八点幂律拟合 **loss ∝ tokens^(−0.060)**,2B→204.8B 从 4.465
一路降到 3.434,**跨 0.2→16 epoch 单调下降、无平台、无拐点**。含义:100M 模型
在 OWT2 上反复过 16 遍数据仍在受益,**data scaling 收益远未耗尽**。

### 2. ★分尺度斜率差 17×——CADENCE 特色 signature
把损失按尺度轴拆开,两条曲线斜率天差地别:
- **coarse（语义,q1-q32）:幂律指数 −0.009,近乎水平**（4.195→4.009,总降 4%）;
- **fine（词面,q128-q1024）:幂律指数 −0.161,陡降**（4.606→2.316,总降 50%）;
- **斜率比 ≈ 17×**,且 fine 在 2B 时**高于** coarse（词面最欠训）、在 ~6.4B
  处**穿过** coarse 之下,此后一路走低,到 204.8B 仍无收敛迹象。

**这是 next-scale prediction 独有、别人物理上画不出的 scaling 结论**:
data scaling 的收益 ~17:1 压倒性流向**细尺度词面渲染**,而**粗尺度语义规划在
2B 就基本学够、几乎不吃数据**。它把"loss 降了"升级成"降在结构的哪一层":
CADENCE 的层级里,语义计划早饱和,规模几乎全用来提升词面渲染。与自适应实验
（难度/信息集中在中细带）、以及段轴/2D 的机制结论完全自洽。

### 3. 生成质量弱正向,无稳健饱和拐点（交叉榜核对后收窄）
- **R1/R2**:四榜大体**弱正向到持平**,wiki R2 4.06→5.03 稳步升,R1 噪声中
  略升;到 204.8B 未见退化。
- **MAUVE**:**没有跨榜一致的拐点**。wiki MAUVE 在 51.2B 达峰 0.195 后回落
  （0.174→0.161）,但 **wikisource 反而一路升**（0.091→0.105→0.108）,
  tinystories/1bw 全程 <0.008 属地板噪声。因此"wiki MAUVE 51.2B 拐点"是
  **单榜现象,不构成稳健的预算饱和信号**——报告时不上升为结论。

**综合:到 204.8B（16 epoch）teacher-forced loss 与生成质量均未出现稳健饱和
拐点。** 唯一稳健的结构信号是分尺度剪刀差。

### 4. ★判官 Gen-PPL（+熵并读）——最干净的生成侧信号,同样无拐点
协议主指标 Gen-PPL（gpt2-large 判官,prompt 条件,语料级 token-mean）在**全 8 点
× 全 4 benchmark**上计算,并按项目规矩与 unigram 熵、参考锚点并读。

| 12.8B | 1.0 | 253.9 | 236.3 | 120.1 | 685.3 | 11.10 |

| 参考(human) | — | 20.0 | 19.5 | 7.2 | 45.1 | 11.34 |

三点结论:
1. **Gen-PPL 四榜全部单调降到 204.8B,无回升**（wiki 幂律 b=−0.132、ws −0.083、
   ts −0.102、1bw −0.092）。**本想用 PPL 抓"重复数据→生成变不流畅"的隐藏过拟合
   拐点,结果它反着走**:16 epoch 仍在变流畅。→ **和 test loss 一致,把"无饱和
   拐点"从 teacher-forced 侧延伸到自由生成侧**。
2. **PPL 的下降是真流畅度提升,不是多样性塌缩**:熵全程贴参考（wiki 11.20 vs 参考
   11.34,四榜差 ≤0.32）且随 token 微升。**这正是"PPL 必和熵并读"的意义**——
   对比 ELF 靠熵 0.4–0.55 的分布压缩换低 PPL,CADENCE 是参考级多样性下的真流畅。
3. **PPL 斜率（wiki −0.132）落在总 loss（−0.060）与 fine loss（−0.161）之间**——
   判官流畅度≈细尺度词面渲染,与"data scaling 收益几乎全在 fine"的机制链自洽。

（MAUVE@1024 全 8 点四榜塌地板 0.005–0.011,印证协议波旧结论"@1024 无区分度、
截断长度承担全部信号",对定预算无信息。）

## 对 model scaling 的指示（data scaling 一阶结论）

> 本节结论经 4 路独立对抗审查（各读原始数据、专门去找预算拐点）+ 综合复核，
> 4 路引用数字全部核对无误；结论"无 strong 拐点"在对抗下幸存。

0. **★三重确认"无质量强加的预算上限"**:定预算的锚点是最干净的 test loss
   （确定性、逐尺度可分解）——它到 16 epoch 单调降。两条独立的生成侧信号
   交叉验证同一结论:**判官 Gen-PPL 四榜单调降无回升**（自由生成侧,确定性），
   **且四榜 R1/R2/MAUVE 无跨榜一致拐点**（每个候选拐点都是单榜或噪声内,且被
   另一榜同指标反驳——wiki-MAUVE 51.2B 峰被 ws 的单调升否掉,正是撤回过一次的
   那个假象）。三者一致 → **重复数据到 16 epoch 都没有把生成质量拖垮的拐点,
   预算不是被质量卡住,而是被算力卡住**。唯一真发现是**边际递减（非饱和）**,
   且它本身也吵（总 loss 每翻倍增益在 51.2→102.4B 掉到 −0.027、又在
   102.4→204.8B 反弹到 −0.120，非单调,钉不住拐点位置）。

1. **★落定建议:固定预算取 100B（8 epoch）为运行点,50B（4 epoch）兜底。**
   一句话论证:*无跨榜出噪声的拐点（总 loss/fine loss/四榜 Gen-PPL 全部单调降
   到 204.8B），故质量不设上限；但边际收益在 ~100B 后坍缩——102.4→204.8B 这一
   翻倍只买 −0.12 bits 总 loss / −0.16 fine / ≤7% Gen-PPL，而 51.2→102.4B 翻倍
   买 −0.16 / −0.28 / 至多 −12% Gen-PPL——所以 100B 已吃掉 token 预算能买的
   几乎全部质量，算力紧时退 50B（省 2×）。* 选 100B 而非 50B,是因为 Gen-PPL 在
   51.2→102.4B 还付了最大的尾部翻倍（wiki −27.4/−12%、ws −23/−11%）；不取 200B,
   是因为最后那 4×（51.2→204.8B）只买 −0.147 bits 总 loss,比单个 25.6→51.2B
   翻倍还少。

2. **★★最大风险(load-bearing 假设):此预算在 100M + 重复数据上量得。**
   100B = ~8 epoch,而 unique 语料只有 **12.72B OWT2 token**——**真正的约束是
   unique-token 供给,不是重复次数**。大模型过拟合重复数据更快,**被撤回的 val
   粗尺度回升,正是可能在更大模型上变成"真" test 拐点的那个失效模式**（在 100M
   上被 test 否证,不保证在大模型上仍被否证）。缓解:model scaling 每个规模点
   先复查 test_coarse_q1_32 与总 test loss 有无重复驱动的回升,一旦出现就退到
   50B（4 epoch,重复更少）。

3. **分尺度互补假设**:data scaling 的收益几乎全在 fine（词面）,而 coarse
   （语义）在 ~6–13B 就取到 204.8B 地板的 0.12–0.13 bits 之内（其后每翻倍增益
   都在 ~0.027 bit 噪声带内、且这个 coarse 早饱和形状被撤回过两次故弱权重）。
   若放大模型主要提升 coarse（语义容量),则 model scaling 与 data scaling 改善
   的是层级的不同层——**这是 model scaling 阶段值得专门用同一张分尺度图验证的
   假设**;若 model-scaling 目标单是语义容量,6–13B token 即够（但整模型跑因
   fine 未饱和仍需 50–100B）。
