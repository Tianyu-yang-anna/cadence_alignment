## 0. 口径
- **语料**：OWT2（12.8B token，GPT-2 BPE；ELF 用 T5 重分词同语料 13.75B）。
- **预算档**：严格 2B = 7630 步×256×1024 梯度 token（所有 baseline 同额）；
  全量 12.8B = 48800 步 ≈ 1 epoch（独立档，表格分层，不与 2B 并读）。
- **侧预算**：CADENCE 冻结 PQ-VQVAE tokenizer = ELF encoder 预训 = 39.3B token 逐字节同额。
- **NFE**：每生成 1024 token 的 backbone 前向数（CFG 双分支计入）；`22+88` = 22 主干 + 88 次 4.16M 小采样头。
- **benchmark**：Wikipedia / WikiSource / TinyStories / 1BW，各 test n=1000 一枪制；sel n=250 两集（选择用，不与 test 混读）。
- **指标**：主=MAUVE@256、Gen-PPL(gpt2-large 判官,prompt 条件)、unigram 熵；辅=R1/R2/RL/BERTScore/distinct-2；MAUVE@1024 作全长上界（2026-09-08 协议变更，已披露：@1024 全场塌地板，256 截断承担区分度；判官 PPL 必与熵并读）。

## 5. 结论排序（给摘要用）
1. **零外部权重低 NFE 档（2B）**：CADENCE 段轴主线对 BD3 wiki R1+MAUVE 双超、
   NFE 1/46.5；四家传统 baseline（AR/MDLM/CMLM/SSD-LM）2B 下或退化或全面落后。
2. **机制主张**：段间解码顺序（段轴 MaskGIT）是尺度内唯一有效轴（三轴单变量+
   K 曲线单调+2D 三重否定）；多掩码训练 = 恢复被摊薄的监督效率（M=8 甜点），
   对饱和主线中性。
3. **数据缩放**：12.8B 全量档 R1 +5.5、判官 PPL 653→338、参考级多样性保持；
   2D 混合训练在大数据下反超专训。
4. **对 ELF（最强 baseline）**：优势分解后，全对齐格上两家是"各有所长的同侪"
   （CADENCE：R1/TS/多样性/低 NFE 原生；ELF：R2/MAUVE/流利度）；
   "预训练上下文嵌入空间作基底"是其真机制增益（三点归因：随机=地板、
   自语料 39.3B=1T 级），方法学启示=侧预算花在"预测性空间"回报高于"重建保真"。
5. **协议发现**：MAUVE 只在固定协议内可比（num_buckets 换簇排序翻转；@1024
   全场塌地板=256 截断承担区分度）；判官 PPL 必与熵并读（SSD-LM/AR 被锚点
   戳穿）；sel 单格 MAUVE 不可判方向（n=250 sd 3.2~5.3，多次 sel→test 倒挂）。
